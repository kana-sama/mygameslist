# Смарт-заметки для авторов

Смарт-заметка — программа из репозитория с собственным JSON-стейтом. Приложение
предоставляет карточку, необязательное большое окно, сохранение и изображения.
Программа строит интерфейс обычными DOM API, без регистрации компонента приложения
или установки npm-пакетов. Полный контракт: [спецификация](superpowers/specs/2026-10-21-smart-notes-design.md).

## Исходные файлы

Создайте папку `smart-notes/<uuid>/` внутри папки игры. UUID заметки стабилен,
совпадает с именем папки и не пересекается с ID других заметок. Пример независим
от игровых данных:

```text
smart-notes/6ce72042-e2cf-4d5e-bc68-477170288465/
  note.json
  preview.js
  page.js
  view.js
  view.css
  templates/page.html
```

`note.json`:

```json
{
  "format": "smart",
  "version": 1,
  "apiVersion": 1,
  "id": "6ce72042-e2cf-4d5e-bc68-477170288465",
  "title": "Учебный счётчик",
  "entrypoints": { "preview": "preview.js", "page": "page.js" },
  "rank": 1024,
  "createdAt": "2026-10-21T00:00:00.000Z",
  "updatedAt": "2026-10-21T00:00:00.000Z",
  "state": { "count": 0 },
  "assets": []
}
```

`title` обязателен. `preview` обязателен, `page` можно опустить. `groupRank`,
`doubleHeight` и `doubleWidth` имеют обычную семантику размещения заметок.
Точки входа — относительные пути к существующим `.js` внутри этой папки.
Вложенные обычные файлы сохраняются с исходными байтами и относительными путями.
Симлинки, выход за пределы папки, коллизии путей и неподдерживаемые версии
отклоняются. Все файлы, кроме корневого `note.json`, образуют программу.

Сборщик вычисляет описатель и хеш программы; их не нужно писать в `note.json`.
Стейт не влияет на адрес программы. Публикация стейта сохраняет файлы программы,
а переименование игры переносит их вместе с папкой игры.

## Монтирование

Обе точки входа экспортируют `mount(root, api)`:

```js
// preview.js
import { mountCounter } from "./view.js";
export function mount(root, api) {
  return mountCounter(root, api);
}
```

```js
// view.js — пригоден и для preview, и для page
export async function mountCounter(root, api) {
  const response = await fetch(new URL("./view.css", import.meta.url), {
    signal: api.signal,
  });
  if (!response.ok) throw new Error("Не удалось загрузить стили");
  const style = document.createElement("style");
  style.textContent = await response.text();
  api.signal.throwIfAborted();

  const output = document.createElement("output");
  const button = document.createElement("button");
  button.textContent = "+1";
  const error = document.createElement("p");
  error.setAttribute("role", "alert");
  root.append(style, output, button, error);

  function render({ value }) {
    // Проверка предметной схемы принадлежит автору программы.
    if (!value || typeof value !== "object" || !Number.isInteger(value.count)) {
      throw new Error("Неподдерживаемый стейт счётчика");
    }
    output.textContent = String(value.count);
  }
  render(api.state.get());
  const unsubscribe = api.state.subscribe(render);
  async function increment() {
    try {
      await api.state.update(value => ({ ...value, count: value.count + 1 }));
      error.textContent = "";
    } catch (reason) {
      error.textContent = reason.message;
    }
  }
  button.addEventListener("click", increment);
  return () => {
    unsubscribe();
    button.removeEventListener("click", increment);
  };
}
```

```js
// page.js — загружается только при открытии окна
import { mountCounter } from "./view.js";
export function mount(root, api) {
  return mountCounter(root, api);
}
```

```css
/* view.css */
:host { font: inherit; color: inherit; }
output { display: block; font-size: 2rem; }
```

`root` — HTMLElement внутри отдельного открытого ShadowRoot. Стили загружайте
внутрь root; они не оформляют соседние заметки или оболочку. Шрифт и основной цвет
наследуются. Относительные импорты, `fetch(new URL("./templates/page.html",
import.meta.url))` и аналогичная загрузка CSS используют адрес модуля. HTML можно
добавить в root как доверенный шаблон; вставленные `<script>` хост не исполняет.
Не импортируйте внутренние модули приложения и не импортируйте `page.js` из
preview: это нарушит ленивую загрузку большого представления.

`mount` бывает синхронным или асинхронным, возвращает функцию cleanup либо
`undefined`. Cleanup освобождает созданные программой обработчики, таймеры,
наблюдатели и собственные URL. Используйте `api.signal` для асинхронной работы.
После обычного закрытия окна хост отменяет его scope; поздняя cleanup-функция
всё равно вызывается.
Поздно созданный DOM остаётся в отсоединённом контейнере. Браузер может кешировать
импортированный модуль после закрытия окна.

Превью загружается при первом появлении в видимой области и остаётся смонтированным
при прокрутке. Открытие окна создаёт независимое представление той же записи;
закрытие очищает только окно. Изменение стейта не вызывает повторный mount.

## API версии 1

Типы ниже описывают API для обычного JavaScript; их не нужно импортировать:

```ts
type Json = null | boolean | number | string | Json[] | { [key: string]: Json };
type AssetRef = { $asset: string };
type Snapshot = { value: Json; revision: string };
type ImageMetadata = {
  id: string; assetId: string; ref: AssetRef; kind: "image"; mime: "image/webp";
  originalName: string; alt: string; width: number; height: number; byteLength: number;
};
interface Api {
  version: 1;
  mode: "preview" | "page";
  signal: AbortSignal;
  state: {
    get(): Snapshot;
    subscribe(listener: (snapshot: Snapshot) => void): () => void;
    update(reducer: (value: Json) => Json): Promise<void>;
    set(value: Json, options: { expectedRevision: string }): Promise<void>;
  };
  assets: {
    list(): ImageMetadata[];
    read(ref: AssetRef): Promise<Blob>;
    url(ref: AssetRef): Promise<{ url: string; release(): void }>;
    upload(blob: Blob, options: { name: string; alt?: string }): Promise<AssetRef>;
    release(ref: AssetRef): void;
  };
  page: {
    open(): boolean;
    close(): void;
    beforeClose(handler: () => void | Promise<void>): () => void;
  };
}
```

`get` возвращает независимый снимок. Изменение этого объекта ничего не сохраняет.
`subscribe` уведомляет об успешно сохранённых изменениях и не вызывает слушателя
сразу: начальный снимок берите через `get`. Оставшиеся подписки снимаются при
закрытии scope. Идентификатор заметки в методы API не передаётся.

Записи сериализованы. Синхронный reducer `update` получает копию самого свежего
сохранённого стейта; не делайте в нём побочных эффектов или асинхронной работы.
`set` проверяет непрозрачную ревизию из `get`: устаревший `expectedRevision`
вызывает ошибку. Предметное автоматическое слияние отсутствует. Превью и окно
получают изменения одной записи. Неизменившийся JSON не создаёт новую правку.

Стейт допускает только обычный JSON: без `undefined`, функций, циклов, BigInt,
нечисловых чисел и объектов специальных типов. Неуспешная запись, нехватка места,
неверные ссылки и конфликт отклоняют Promise и сохраняют прежнее состояние.
Обрабатывайте ошибки в программе; хост также показывает ошибку сохранения.
Новая запись уже закрытого scope отклоняется. Начатая атомарная запись завершается
целиком либо отклоняется целиком.

Правки сохраняются в существующий локальный патч. Публикация выполняется общим
действием синхронизации. Действуют прежние правила экспорта, восстановления, undo,
конфликтов другой вкладки и проверки опубликованной базы. Если программа изменилась,
неопубликованный стейт старой программы становится восстанавливаемым конфликтом;
хост не передаёт его обновлённому коду. Миграция уже опубликованного предметного
JSON — ответственность автора программы; универсальных миграций нет.

## Изображения

Единственная зарезервированная структура JSON — объект ровно с одним полем
`{"$asset":"<sha256>"}`. Дополнительные поля или неверный ID отклоняются.
Ссылки находятся рекурсивно, включая массивы; повторы объединяются. Обычная строка
с ID или URL не создаёт владение. Другие ключи приложения не интерпретируются.

`upload` принимает File/Blob изображения, включая результат Canvas; `name`
обязателен и непуст, `alt` по умолчанию пуст. Готовый WebP сохраняется, остальные
поддерживаемые форматы преобразуются в lossless WebP без изменения размеров.
Программа может обработать исходник в памяти и загрузить только результат.

```js
const ref = await api.assets.upload(file, { name: file.name, alt: "Пример" });
try {
  await api.state.update(value => ({ ...value, picture: ref }));
} finally {
  // Снимает временное удержание загрузки, не удаляет сохранённую ссылку.
  api.assets.release(ref);
}
const image = document.createElement("img");
const handle = await api.assets.url(ref);
image.src = handle.url;
root.append(image);
// При замене изображения или cleanup:
handle.release();
```

Успешная загрузка сначала сохраняет байты и временно удерживает их за scope.
Сохранение ссылки создаёт владение заметкой; удаление последней ссылки делает
файл кандидатом для безопасной очистки. Незавершённые загрузки, живые URL,
потребители других scope/вкладок, undo, recovery и ожидающая публикация защищают
байты. Освобождайте ненужные загрузки; закрытие scope освобождает оставшиеся
удержания и URL. При ошибке записи не считайте изображение прикреплённым.

`list` возвращает метаданные сохранённых изображений. `read` и `url` доступны
для ссылок сохранённого стейта этой заметки и её доступных загрузок; произвольные
чужие ID не открываются. Полученный Blob можно обрабатывать в памяти. URL —
временный ресурс представления, в JSON его не записывают.

Список `assets` в исходном `note.json` соответствует уникальным ссылкам стейта,
отсортирован по ID и содержит `assetId`, `originalName`, `alt`. Он автоматически
обновляется при API-записи; метаданные и байты проверяются общим механизмом.
Галерея вложений рядом с превью не добавляется. Статические ресурсы программы
не участвуют в очистке загруженных изображений.

## Оболочка и управление

Хост выводит один `h1` над превью. При наличии page заголовок — кнопка открытия;
обычный клик по неинтерактивному превью тоже открывает окно. Кнопки, ссылки, поля,
выделение текста, отменённые события, drag и путь с `data-smart-no-open` не
открывают его. Это работает и во вложенных Shadow DOM. `api.page.open()` возвращает
`false`, если страницы нет. `api.page.close()` закрывает окно этой заметки.

В page-представлении `api.page.beforeClose(handler)` регистрирует обработчик
обычного закрытия и возвращает отписку. Крестик, Escape и `api.page.close()`
ожидают все обработчики до отмены scope и cleanup. Внутри обработчика можно
сохранить отложенный черновик и дождаться уже начатых записей. Повторные запросы
закрытия во время ожидания объединяются. Ошибка оставляет окно и scope открытыми,
хост показывает её; следующее закрытие повторяет обработчики. Без обработчиков
закрытие остаётся немедленным. Подписки удаляются при dispose scope.

```js
const stopBeforeClose = api.page.beforeClose(async () => {
  await flushDraft(); // Promise должен отклоняться при ошибке сохранения.
});
// В cleanup: stopBeforeClose();
```

Этот lifecycle относится к page scope при обычном закрытии модального окна.
Он не запускается при teardown превью, переходе на другую страницу, конфликте,
смене программы или завершении вкладки/браузера: эти пути немедленно отменяют
scope. Не полагайтесь на асинхронную запись после завершения браузера. API
`state.update`/`set` не откладывают записи; debounce и черновики принадлежат
программе заметки. Нельзя сохранять такой черновик только из cleanup: к этому
моменту scope уже отменён.


Окно имеет отступы 24 px при ширине больше 680 px; при ширине 680 px и меньше
занимает весь экран. Фон инертен, прокрутка страницы заблокирована, фокус
удерживается внутри окна с учётом вложенных Shadow DOM и возвращается к инициатору.
Кнопка закрытия и Escape закрывают окно; фон — нет. Обработчик внутри программы
может потребить Escape через `preventDefault()` или `stopPropagation()`.

Сайт позволяет менять размещение и размеры карточки. Код, название, контракт,
точки входа и принадлежность заметки меняются через репозиторий. Создание,
конвертация и отдельное удаление смарт-заметки в редакторе сайта недоступны;
удаление всей игры удаляет её вместе с программой. Просмотр локальных правок
показывает экранированный JSON и не исполняет программу.

Ошибка импорта, отсутствие `mount` и сбой mount показываются локально.
Сетевую загрузку можно повторить; ошибка вычисления модуля может требовать
обновления страницы после исправления кода. Shadow DOM изолирует DOM и CSS,
но доверенный JavaScript из репозитория имеет обычные возможности браузера;
это не sandbox для чужого кода.
