# Активная карточка смарт-заметки

Пользователь сообщает, что клик по smart note не делает её активной.
Страница уже отслеживает pointerdown, click и focusin на document capture
и передаёт interactionActive в InlineNoteCard, но smart ветка теряет проп:
SmartSortableNoteCard не получает его и не ставит общий класс активности.

- Смарт-карточка использует существующее состояние активности страницы
  и общий note-card--interaction-active, как обычная заметка.
- Pointer/click/focus на оболочке, заголовке и нативных контролах открытого
  Shadow DOM превью активируют карточку. Активна не более одной заметки.
  Взаимодействие с другой карточкой переключает активность, вне карточек —
  сбрасывает; движение указателя не сбрасывает выбранную карточку.
- Не добавлять отдельный state, обработчики или CSS для smart; сохранить
  текущие open/fullscreen, drag, state/assets API и focus/modal lifecycle.
  Активность сама по себе не сохраняет данные и не меняет программу.
- В DESIGN.md закрепить общий active-state контракт для всех форматов.

Проверка: generic GamePage regression с smart и обычной карточкой,
синтетическим preview и Shadow DOM контролом; воспроизвести отсутствие класса
до исправления, затем проверить pointer/click/focus, переключение и сброс,
отсутствие вызовов сохранения. Focused acceptance/UI tests и build.
