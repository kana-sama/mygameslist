# Barbuta: личный атлас

Пользователь поручил самостоятельно выбрать дизайн, реализовать быстро и проверить,
отдельным коммитом после фреймворка. Последующие уточнения: обязательное определение
позиции по миникарте, пакетная загрузка и качественное увеличение экранов.

## Контракт

- Одна смарт-заметка внутри UFO 50, без изменений приложения или его знания о Barbuta.
- Пустая личная карта 8×8. Превью показывает найденные комнаты; неразгаданные серые,
  разгаданные цветные. На странице выбор комнаты, текст и отметка «разгадано».
- Файловый выбор с multiple, перетаскивание пачки, вставка изображений. Каждый файл
  независимо распознаётся, обрезается, сохраняется через API и попадает по координате.
  Пользователь не назначает координаты. Нераспознанные файлы перечисляются отдельно.
- Повторный скрин комнаты заменяет изображение, сохраняя текст и прогресс. Последний
  успешно обработанный файл комнаты побеждает; сбой одного файла не отменяет остальные.
- Текст и флаг сразу записываются через API; загруженные изображения используют
  стандартное владение ассетами, URL и GC фреймворка.
- Сохраняется только игровое поле в native 256×184, lossless WebP без квантования
  цветов. Большой просмотр использует тот же файл с целочисленным увеличением ×1–×6,
  без сглаживания. Полные исходники не занимают хранилище.

## Нормативный образец вырезки

Пользовательский файл `codex-clipboard-736c037e-5a99-477d-ad36-c8770eeff4a2.jpg`
(1280×720), сохранён также рядом с программой как `example.jpg` для добровольной
пробы импорта. В сетке UFO 50 384×216: поле x=64,y=16,w=256,h=184;
мини-карта x=16,y=168,w=32,h=32, ячейки 4×4, красная точка образца — E4.
Боковой HUD и красная рамка исключаются, нижний каменный ряд сохраняется.
Распознавание требует единственную красную ячейку и светлую сетку миникарты;
неуверенный результат не создаёт запись в случайной комнате.

Дизайн: чёрный фон, кремовая типографика, малиновый акцент рамки, зелёный прогресс,
пиксельные изображения. Исследованы [скриншот Syltefar](https://syltefar.com/screenshot/?id=4269)
и [карта Two-Reeler](https://two-reeler.com/barbuta-map/); готовая карта со спойлерами
не включается. На узком экране карта и инспектор идут друг под другом.

## Проверка

Временный проверяющий скрипт: координаты, неоднозначная/отсутствующая точка,
точная вырезка, сохранение заметок при замене, ограничение native-размера.
Реальный образец: распознан E4 и корректная обрезка. Браузер: пачка с дубликатом и
ошибочным файлом, запись текста и флага, большой пиксельный просмотр, перезагрузка,
превью; 1280×800 и 390×844. Затем data:validate и build. Постоянных тестов,
закрепляющих содержимое реальной базы, не добавлять.
