# Центрирование табличного чекбокса без текста

## Задача

Устранить описанное пользователем смещение одиночного чекбокса в ячейке заметки, исправив причину появления пустого элемента в разметке.

## Причина

`MarkdownRenderBody` добавляет после `label` пустой `span` с `id`, когда ячейка не содержит текста, но передана `checklistSearchNoteIdentity`. Этот узел служит пустой целью `aria-describedby`. В `.markdown-table-task` действует `display: flex; gap: 5px`, поэтому даже пустой второй элемент добавляет промежуток: центрируется группа шириной 21 px вместо единственного label шириной 16 px. Чекбокс смещается влево на 2.5 px.

Поиск и переход к пункту используют `data-checklist-search-target-id` и structural guard на внешнем контейнере; пустой `span` для них не нужен. Доступное имя уже задано через `aria-label` с контекстом строки и колонки.

## Требования

1. Ячейка только с `[ ]`, `[x]` или `[-]` содержит единственный элемент управления без пустого текстового `span`, независимо от подключения поиска.
2. `aria-describedby` присутствует только при наличии реального текстового содержимого и соответствующего элемента с `id`. Доступное имя одиночного чекбокса сохраняется.
3. Идентификатор цели поиска, structural guard, подсветка, фокус и переключение состояния сохраняются. Текстовые ячейки сохраняют содержимое и связь описания.
4. Исправление находится в условном рендере. CSS-отступы, позиционирование, размеры, данные и форматы Markdown не меняются.

Согласованная область работ — исправление причины и центрирования, прямо запрошенное пользователем. Это уточнение реализации существующего поведения, без нового визуального дизайна.

## Проверка

| Требование | Проверка |
| --- | --- |
| 1 | Компонентный регрессионный тест с искусственной таблицей: единственный дочерний `label`, нет пустого `span`; три состояния, поиск включён и выключен |
| 2 | Проверка доступного имени и отсутствия пустого `aria-describedby`; связь текстовой ячейки разрешается в непустой элемент |
| 3 | Существующие проверки поисковых маркеров и подсветки, тест переключения; связанные тесты поиска и Markdown |
| 4 | `jj diff`; браузерное сравнение центров checkbox и ячейки с неизменным CSS на искусственной таблице |

Прочитаны текущая реализация `Markdown.tsx`, CSS таблиц, `GamePage.tsx`, тесты `markdown-tasks.test.tsx` и спецификации `2026-09-01-page-checklist-search-design.md`, `2026-08-13-table-checkbox-backgrounds-design.md`. Контракт поиска не требует пустого DOM-описания.
