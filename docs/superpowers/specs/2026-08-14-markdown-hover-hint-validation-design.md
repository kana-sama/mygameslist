# Валидация Markdown-подсказок

## Цель

Разрешить сохранять заметки и отзывы с уже поддержанным синтаксисом `[text]("description")`, не ослабляя проверку настоящих Markdown-ссылок.

## Поведение

- Точная однострочная конструкция `[text]("description")` не считается ссылкой и проходит `validateMarkdown`.
- `description` остаётся обычным текстом и может содержать пробелы и Markdown-подобные символы, кроме ограничивающей кавычки и перевода строки.
- Настоящие ссылки продолжают проверяться через `isSafeLink`; небезопасные схемы по-прежнему отклоняются.
- Исправление не меняет рендеринг, UI или формат сохранённых данных.

## Проверка

Один доменный regression-тест подтверждает, что библиотека с Markdown-подсказкой валидна, а небезопасная настоящая ссылка всё ещё невалидна.
