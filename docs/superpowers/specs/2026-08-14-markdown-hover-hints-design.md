# Markdown-подсказки по наведению

## Цель

Поддержать inline-синтаксис `[text]("description")` для текста с нативной системной подсказкой без создания ссылки и без перехода по клику.

## Синтаксис и содержимое

- Однострочная конструкция `[text]("description")` распознаётся как Markdown-подсказка.
- `description` помещается в HTML-атрибут `title` как обычный текст: Markdown внутри него не разбирается.
- Подпись `text` использует существующий inline-Markdown-рендеринг.
- Обычные Markdown-ссылки сохраняют прежнее поведение.
- Некорректная или незакрытая конструкция остаётся обычным текстом.

## Внешний вид и поведение

- Подпись наследует цвет окружающего обычного текста и не получает цвет внешней ссылки.
- Единственные визуальные признаки подсказки — прерывистое нижнее подчёркивание и курсор `help`.
- При наведении браузер показывает нативную подсказку из `title`.
- Клик ничего не открывает и не меняет; собственного тултипа, оверлея, затемнения и React-состояния нет.

## Реализация

Существующий общий inline-токенизатор получает отдельный вариант конструкции без URL. `Markdown.tsx` рендерит его как неинтерактивный `span` с `title` и отдельным CSS-классом, сохраняя текущий рекурсивный рендеринг подписи и исходные позиции.

## Проверка

Один точечный компонентный тест подтверждает `title`, отсутствие ссылки, обычный цвет текста и отдельный CSS-класс. Существующие тесты и сборка подтверждают, что обычные ссылки и остальной Markdown не получили регрессий.
