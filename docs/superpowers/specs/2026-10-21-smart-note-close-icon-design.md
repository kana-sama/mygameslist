# Центрированный крестик smart-note modal

Пользователь показывает перекошенный крестик в кнопке закрытия. Сейчас это
шрифтовый символ × с baseline/line-height вместо геометрически центрированной
иконки. Заменить его симметричной SVG-иконкой и центрировать внутри прежней
32×32 кнопки. Сохранить доступное имя, focus/hover, закрытие и размер header.
Общий сервис остаётся независимым от игры.

клавиатурный фокус и закрытие. Для CSS-only геометрии новый unit-test не нужен.
