# Сворачиваемые группы строк Markdown-таблиц

## Цель

Добавить в Markdown-заметки группы строк внутри одной таблицы. Каждая группа имеет полноширинный заголовок, сворачивается независимо, показывает прогресс находящихся в ней чекбоксов и получает зелёное завершённое состояние.

## Синтаксис

Заголовок группы записывается как строка таблицы с одной ячейкой и обрамляется сверху и снизу обычными разделителями таблицы:

```markdown
| Уровень                 | ✓   | TW  | SiP | HC  |
|-------------------------|-----|-----|-----|-----|
| Philosopher's Stone                             |
|-------------------------|-----|-----|-----|-----|
| The Magic Begins        | [x] | [x] | [x] | [ ] |
| Out of the Dungeon      | [x] | [x] | [x] | [ ] |
| A Jinxed Broom          | [x] | [x] | [ ] | [ ] |
|-------------------------|-----|-----|-----|-----|
| Chamber of Secrets                              |
|-------------------------|-----|-----|-----|-----|
| Floo Powder!            | [x] | [ ] | [ ] | [ ] |
| Dobby's Plan            | [ ] | [ ] | [ ] | [ ] |
```

Стандартный разделитель под шапкой одновременно служит верхней границей первой группы. Для каждой следующей группы отдельный разделитель перед заголовком визуально отделяет её от последней строки предыдущей группы.

Специальной считается только полная конструкция «разделитель, одноклеточный заголовок, разделитель». Это не меняет значение обычных строк существующих GFM-таблиц.

## Отображение и взаимодействие

- Заголовок занимает всю ширину таблицы и визуально отделён сверху и снизу.
- Вся строка заголовка является кнопкой сворачивания и доступна с клавиатуры.
- Сворачивание скрывает только строки выбранной группы. Шапка таблицы, заголовок самой группы и соседние группы остаются видимыми.
- Состояние каждой группы сохраняется вместе с существующими состояниями свёрнутых checklist-секций заметки.
- Сохранённое состояние группы не меняется при добавлении постороннего текста выше таблицы.
- Переключение чекбокса в строке группы продолжает обновлять исходный `[ ]` или `[x]` без открытия редактора заметки.

## Прогресс и завершение

- Заголовок показывает `N/M`, где `M` — количество всех чекбоксов в строках группы, а `N` — количество отмеченных чекбоксов.
- Если `M > 0` и `N = M`, заголовок группы и его total становятся зелёными.
- После переключения чекбокса total и завершённое состояние обновляются сразу после сохранения заметки.
- Группа без чекбоксов остаётся сворачиваемой, но не показывает total и не получает зелёное состояние.
- Чекбоксы сгруппированных строк продолжают учитываться в totals внешних Markdown-заголовков ровно один раз.
- Существующее зелёное состояние полностью отмеченной обычной строки таблицы сохраняется.

## Совместимость

- Таблицы без групп отображаются и редактируются как прежде.
- В одной таблице могут находиться несколько независимых групп.
- Обычные строки вне распознанной группы не исчезают и не присоединяются к группе молча.
- Существующие правила inline-Markdown, выравнивания столбцов, экранированных вертикальных черт и интерактивных табличных чекбоксов сохраняются.

## Критерии приёмки

1. Пример из раздела «Синтаксис» отображается одной таблицей с двумя полноширинными заголовками групп.
2. Каждая группа сворачивается и раскрывается независимо; состояние сохраняется после повторного отображения заметки.
3. `Philosopher's Stone` и `Chamber of Secrets` показывают собственные totals только по своим строкам.
4. После отметки всех чекбоксов конкретной группы её заголовок становится зелёным; незавершённая соседняя группа не меняется.
5. Клик по чекбоксу меняет правильный маркер в исходном Markdown и не открывает редактор заметки.
6. Несгруппированные GFM-таблицы проходят существующие проверки без изменения поведения.
