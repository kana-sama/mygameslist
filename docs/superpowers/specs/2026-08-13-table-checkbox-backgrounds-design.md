# Зелёные фоны табличных чекбоксов

## Цель

Показывать завершённость табличных чекбоксов зелёным фоном на трёх уровнях: отдельной отмеченной ячейки, полностью отмеченной строки и полностью отмеченной колонки.

## Поведение

- Ячейка с активным чекбоксом получает зелёный фон.
- Если в строке есть хотя бы один чекбокс и все чекбоксы строки активны, зелёный фон получают все ячейки строки.
- Если в колонке есть хотя бы один чекбокс и все чекбоксы колонки активны, зелёный фон получают заголовок и все обычные ячейки этой колонки.
- Ячейки без чекбоксов не мешают завершению строки или колонки: учитываются только фактически присутствующие чекбоксы.
- Заголовки групп с `colspan` не считаются отдельными ячейками конкретной колонки.
- Существующие зелёный текст завершённой строки, выравнивание, группы и переключение исходного Markdown сохраняются.

## Реализация

Рендер таблицы один раз вычисляет завершённость каждой колонки по всем строкам. На `th` и `td` выставляются неперсистентные `data-checklist-checked` и `data-checklist-column-complete`, а существующий класс завершённой строки продолжает отмечать всю строку. Общий `--success-wash` задаёт одинаковый зелёный фон всем трём состояниям.

## Проверка

Компонентный тест должен одновременно подтвердить фоновые маркеры активной ячейки, полностью активной строки, полностью активной колонки и отсутствие завершённости у частично активной колонки.
