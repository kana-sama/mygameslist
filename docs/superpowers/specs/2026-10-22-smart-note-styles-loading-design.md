# Загрузка стилей смарт-заметок

Пользователь требует показывать загрузку до готовности всех стилей, чтобы вместо
превью или страницы не появлялись неоформленные изображения. Причина: SmartMount
ожидает import/mount, но не добавленные программой внешние stylesheet links.

- Общий хост обслуживает preview и page без знаний о конкретных программах.
- С первого кадра и до завершения import, mount и загрузки подключённых CSS
  видна только штатная «Загрузка заметки…». Содержимое скрыто и недоступно фокусу.
- Скрытие сохраняет геометрию mount: скрипты могут измерять размеры и строить карту.
  Готовая заметка сохраняет прежние оформление, размеры и взаимодействия.
- Отслеживать stylesheet links внутри mount и вложенных открытых ShadowRoot:
  несколько файлов, уже загруженные sheets, добавление/замена/удаление ссылок.
  Inline styles не требуют ожидания. Новая ожидающая CSS скрывает содержимое
  до готовности, в том числе при асинхронном mount.
- Ошибка CSS показывает локальную ошибку загрузки с повтором; не оставляет
  бесконечный loader и не показывает неоформленное содержимое.
- Закрытие, смена программы и повторная загрузка снимают наблюдателей и слушатели;
  поздние события не возвращают старый DOM. Cleanup вызывается ровно один раз.
- Сохранить lazy loading, независимые scope, beforeClose, сервисные Markdown/UI,
  уведомления shelf об изменении размеров. API и authored scripts не меняются.

Проверка: generic UI regression tests с управляемыми load/error events, initial
async mount и вложенным ShadowRoot; готовность только после последнего CSS,
ошибка/retry, удаление/замена link, teardown. Итоговая сборка и штатные тесты,
focused browser check с задержанным CSS. Без зависимостей и data-specific tests.
