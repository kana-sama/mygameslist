# Barbuta: совместимое чтение загружаемых скриншотов

Пользователь сообщает «Не удалось прочитать изображение» для оригинального
консольного JPEG в Safari. Текущее сообщение появляется исключительно при сбое
`createImageBitmap(file)` и скрывает исходную причину. Образец успешно читался
в Chromium, поэтому требуется совместимый DOM image decode, без обязательной
поддержки ImageBitmap. Конкретное исключение в Safari пока не подтверждено.

Контракт: оригинальный JPEG 1280×720 распознаётся как E4 и сохраняется как
поле 256×184. Работают пачки, PNG и браузеры без createImageBitmap либо с
отклоняющим декодером. Повреждённый файл даёт индивидуальную ошибку; остальные
продолжают импортироваться. Object URL/Bitmap освобождаются также при ошибках.
Не менять позиционирование, crop, lossless-кодирование, модель данных или API.

Проверка временными purpose-built fixtures: недоступный и отклоняющий ImageBitmap,
успешный DOM decode, испорченный файл, освобождение URL. Реальный JPEG проверить
через UI; по возможности проверить WebKit. Если Safari непосредственно не
проверен, явно указать предел проверки.
