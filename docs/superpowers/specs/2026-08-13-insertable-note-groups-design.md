# Вставка групп заметок между существующими

## Цель

Позволить создавать новую анонимную группу заметок после любой существующей группы, а не только в конце списка, не меняя без необходимости файлы уже сохранённых заметок.

## Ранги групп

- Для новых промежутков используется шаг `2048` (`2^11`). Он выдерживает десять последовательных делений пополам в худшую сторону и после десятого деления оставляет доступную целую середину с обеих сторон последней вставки.
- Первая группа пустого списка сохраняет существующий стандартный ранг `1024`; старые ранги не нормализуются и не переписываются заранее.
- Новая группа в конце получает ранг последней группы плюс `2048`.
- Если справа есть группа и между рангами есть целое число, новая группа получает `left + floor((right - left) / 2)`.
- Если соседние ранги отличаются не больше чем на единицу, место освобождается только справа. Первая затронутая правая группа получает свой прежний ранг плюс `2048`, вторая — плюс `4096`, третья — плюс `6144` и так далее.
- Сдвигается минимальный правый префикс: очередная группа включается в сдвиг только если новый ранг предыдущей группы достиг или пересёк её прежний ранг. Как только новый ранг последней сдвинутой группы меньше ранга следующей нетронутой группы, сдвиг останавливается.
- После сдвига ранг новой группы берётся как целая середина между левой группой и первой сдвинутой правой группой.
- Все заметки одной сдвигаемой группы получают один новый `groupRank`; порядок заметок внутри группы не меняется.

Пример: при рангах `[1024, 1025, 1026]` вставка после `1024` сдвигает правые группы в `[3073, 5122]`, а новая группа получает ранг `2048`.

## Интерфейс

- После каждой существующей группы находится одна горизонтальная строка действий.
- Слева остаётся кнопка «Добавить заметку», создающая заметку в текущей группе.
- Справа появляется кнопка «Добавить группу», создающая группу между текущей и следующей группой либо в конце после последней группы.
- Если заметок ещё нет, показывается единственное действие создания первой группы.
- Отдельный вертикальный блок «Новая группа» в конце исчезает; конечные действия используют ту же горизонтальную компоновку, что и действия между группами.
- Создание группы сразу открывает редактор её первой заметки. Пустая группа отдельно не хранится.
- На сохранённой странице необходимые сдвиги правых групп остаются предварительными до сохранения первой заметки. Отмена редактора не сохраняет и не оставляет эти сдвиги.
- В форме новой игры сдвиги остаются частью локального черновика и сохраняются только вместе с игрой.
- Существующее добавление файлов и перенос заметки в новую группу в конце списка сохраняются.

## Проверка

- Чистая проверка рангов покрывает добавление в конец, обычную середину, десять последовательных делений с оставшимся местом слева и справа, а также минимальный сдвиг только правого блока.
- Компонентные проверки покрывают горизонтальные пары действий, создание и сохранение группы между существующими на странице игры, отмену без сдвигов и тот же сценарий в форме новой игры.
