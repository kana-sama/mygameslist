# Barbuta Atlas Implementation Plan

**Goal:** Личный атлас с автоматическим пакетным импортом консольных скриншотов.

**Architecture:** Обычные JS/CSS рядом с note.json внутри игры. Preview и page
разделены; общий model/view, обработка изображений загружается только на странице.
Стейт `{version:1,rooms:{"x,y":{image:AssetRef|null,note:string,solved:boolean}}}`.

**Tech Stack:** Vanilla DOM, Canvas, framework API v1. Без новых зависимостей.

**Spec:** ../specs/2026-10-21-barbuta-atlas-design.md

Ускоренное inline-исполнение по явному «быстро» и исключению AGENTS.md; без
промежуточных коммитов, дополнительных согласований или широкого аудита.

- [x] Создать note.json, model.js (координаты, состояние, распознавание), images.js
  (декодирование, native crop), view.js (URL, сетка), preview.js, page.js и style.css
  в `data/games/ufo-50_7eb56a86-dad9-45a5-9b82-65a32e9deb68/smart-notes/9846ccca-f748-4e79-a666-01c04aaf6e4a/`.
- [x] Реализовать последовательный импорт пачки с прогрессом и отдельными ошибками;
  дубликаты заменяют только изображение. Добавить редактирование, удаление картинки,
  навигацию клавишами и целочисленный большой просмотр; корректный cleanup.
- [x] Проверить чистые функции временным скриптом и реальную вырезку в браузере;
  проверить batch, нераспознанные файлы, запись, reload и оба viewport.
- [x] Выполнить `node --check`, `npm run data:validate`, `npm run build`, удалить
  временные верификаторы; проверить `jj status`/`jj diff`, `jj describe`, `jj new`.

## Результаты проверки

- Временные Node-проверки: все 64 позиции миникарты, отсутствие/двойная точка,
  пять целочисленных масштабов, сохранение текста и флага при замене,
  повторное использование/освобождение/повторное получение URL. Всё прошло.
- Браузер 1280×800: пачка из пользовательского JPEG, native PNG и повреждённого
  JPEG дала одну добавленную комнату E4, одну замену и одну независимую ошибку.
- Финальная сборка: образец 1280×720 определён как E4; изображение 256×184,
  большой просмотр ×3 — 768×552 целиком, с нижним каменным рядом, без рамки и HUD.
  Текст и флаг пережили повторный импорт и перезагрузку, Escape закрывает просмотр.
- Превью содержит 64 ячейки и синхронный прогресс. При 390×844 ширина содержимого
  равна ширине экрана, все восемь рядов карты видны; ошибок в консоли нет.
- `node --check`, `npm run data:validate`, `npm run build` завершились успешно.
  Исходный state остался пустым; браузерные правки относятся только к тестовому origin.
  Временные проверки выполнялись inline, проверяющих файлов в репозитории нет.
