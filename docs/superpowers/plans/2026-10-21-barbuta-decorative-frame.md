## Проверка

- `npm run build` и `npm run data:validate` завершились успешно после финальных
  CSS-изменений. `node --check page.js` прошёл; 17 generic runtime/patch-тестов
  прошли при диагностике импорта. Новых постоянных data-specific тестов нет.
- В браузере проверены 1280×800, 1470×864, 1600×900 и 390×844, Markdown и
  загруженный редактор. Структурно: 64 ячейки, пропорции 32:23, 12px внешних
  отступов desktop / 8px mobile, border 0 и без perimeter pseudo у карты/превью,
  page/sidebar overflow 0. Превью ограничено 350px.
- Проверены пустая и заполненная комнаты, hover и keyboard focus/selection:
  контур ::after находится внутри ячейки. Реальная временная отсутствующая
  картинка дала error-состояние HTTP 404 без переполнения страницы.
- Исполнитель и reviewer напрямую сравнили референсы и итоговые снимки.
  Итог scoped review: approve, замечаний нет.
  Снимки сохранены в рабочей папке визуализаций как `barbuta-details-*.png`.
  Временное dist-only состояние восстановлено, серверы и QA-вкладки закрыты.
- Единичный Safari `blob 1` уже исчез по ответу пользователя. Причина
  не подтверждена; импорт и общий framework этой правкой не изменены.
